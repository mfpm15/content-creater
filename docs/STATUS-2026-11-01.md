# Status proyek — 1 November 2026

Empat produk fokus: ClipperCuan, Video Studio, Article Drafter, Analytics. Cakupan fitur dan batas validasi terbaru: [FEATURE-COVERAGE.md](FEATURE-COVERAGE.md). Rencana awal tetap di [PLAN-TERPADU-2026-10.md](PLAN-TERPADU-2026-10.md); tabel di sana adalah baseline historis, bukan status penyelesaian.

## Implementasi terbaru

- **ClipperCuan:** framing per-shot/crossfade, subtitle editorial dan glossary; ekspor TikTok/Shorts/Reels melalui antrean, loudness dua tahap, hash artefak dan gerbang unduhan. Mask libass mengukur semua frame teks ASS tambahan, termasuk title/CTA/watermark teks. Teks sumber dan gambar tetap di luar cakupan.
- **Editor lokal:** snap batas ke hening opt-in tanpa mengubah cakupan kata/durasi; review pengulangan persis dengan tampilan dua take, revision guard dan konfirmasi talking-head. Fuzzy match hanya review manual.
- **Framing eksperimental:** turn dominasi mulut stabil dengan gate energi audio dan fallback dua panel; cursor screen-recording manual dengan blur fallback. Belum dikalibrasi pada video nyata.
- **Studi referensi:** sampel video lokal 1–120 detik, cuts/median shot, tempo ucapan dan hook literal. Tidak mengklaim memahami struktur cerita.
- **Video Studio:** job review dapat ditemukan/resume, revision guard; varian empat rasio dari salinan plan tetap menunggu review; preview Lottie memakai JSON ekspor yang sama. Review MP4 mengukur stream, loudness/true peak/silence, pacing estimasi dan jarak cut ke grid envelope musik prosedural. Screenshot midpoint/overflow opsional melalui browser terisolasi.
- **Article Drafter:** riset opsional, ledger sumber/kutipan/tanggal, freshness dan kaitan paragraf–sumber; revisi per bagian dengan proposal tersimpan, persetujuan, digest dan backup; flow/mind map lokal SVG+PNG tertanam DOCX. Fetch publik default mati tanpa host allowlist.
- **Analytics:** satuan retensi eksplisit, pemetaan CSV generik lintas platform, kolom tak terpakai dilaporkan, retensi per adegan, observasi lokal 24h/7d dan persetujuan eksperimen. Pengguna menunda CSV asli; schema native Reels/TikTok belum diverifikasi.

## Validasi sesi ini

- Dashboard: 58 tes unittest lulus; smoke startup/HTTP/katalog/redaction lulus.
- Clipper: 191 tes suite penuh lulus, ditambah satu tes studi referensi FFmpeg baru lulus terpisah (192 kasus total).
- Ruff F/E9, syntax JavaScript dan pemeriksaan whitespace lulus.
- Browser Chromium desktop/mobile dengan fixture terisolasi: exact JSON preview Lottie dan escaping, tambah/review/hubungkan sumber artikel, pemetaan CSV, simpan/setujui observasi Analytics; tanpa error JavaScript.
- JSON Lottie juga dimuat dan di-seek dengan player standar `lottie-web` 5.12.2 tanpa error; tidak hanya diuji memakai preview internal.
- MP4 sintetis diukur nyata: loudness -21.8 LUFS/true peak -17.7 dBFS terdeteksi sebagai perlu review; screenshot midpoint berhasil melalui server loopback sementara. Uji tidak memerlukan provider atau credential produksi.
- Benchmark nyata dari sesi sebelumnya: WIRED 14/15 klip framing per-shot dan contact sheet; panel Huang/Musk serta podcast sintetis. Temuan tersebut tidak membuktikan heuristik cursor/turn terbaru sudah tervalidasi.

## Batas dan pekerjaan lanjutan

1. Keenam situs produk referensi belum dapat dibaca (proxy 403); draft allowlist tersimpan tetapi belum diterapkan. Fitur produk mereka belum dipetakan secara terverifikasi.
2. Runtime/provider render/TTS/riset eksternal dan timestamp narasi per kata belum diuji penuh. Tidak menganggap tes sintetis sebagai keberhasilan provider nyata.
3. Benchmark nyata cursor/turn/snap dan ekspor CSV asli menunggu data. Ambang crossfade masih berasal dari sampel terbatas.
4. Beat musik eksternal, transien setelah hening, review visual semua frame, serta analisis semantik hook/payoff referensi belum selesai.
5. Avatar, dubbing/terjemahan, generative B-roll dan publishing/scheduler lintas platform belum tersedia sebagai satu workflow terpadu.
6. Server yang sudah berjalan dapat memakai kode lama; perubahan source perlu restart proses aplikasi. Tidak me-restart pekerjaan pengguna yang sedang berlangsung secara otomatis.
