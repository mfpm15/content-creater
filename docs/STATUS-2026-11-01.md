Empat produk fokus: ClipperCuan, Video Studio, Article Drafter, Analytics. Cakupan fitur dan batas validasi terbaru: [FEATURE-COVERAGE.md](FEATURE-COVERAGE.md). ## Implementasi terbaru

- **ClipperCuan:** framing per-shot/crossfade, subtitle editorial dan glossary; ekspor TikTok/Shorts/Reels melalui antrean, loudness dua tahap, hash artefak dan gerbang unduhan. Mask libass mengukur semua frame teks ASS tambahan, termasuk title/CTA/watermark teks. Teks sumber dan gambar tetap di luar cakupan.
- **Editor lokal:** snap batas ke hening opt-in tanpa mengubah cakupan kata/durasi; review pengulangan persis dengan tampilan dua take, revision guard dan konfirmasi talking-head. Fuzzy match hanya review manual.
- **Framing eksperimental:** turn dominasi mulut stabil dengan gate energi audio dan fallback dua panel; cursor screen-recording manual dengan blur fallback. Belum dikalibrasi pada video nyata.
- **Studi referensi:** sampel video lokal 1–120 detik, cuts/median shot, tempo ucapan dan hook literal. Tidak mengklaim memahami struktur cerita.
- **Video Studio:** job review dapat ditemukan/resume, revision guard; varian empat rasio dari salinan plan tetap menunggu review; preview Lottie memakai JSON ekspor yang sama. Review MP4 mengukur stream, loudness/true peak/silence, pacing estimasi dan jarak cut ke grid envelope musik prosedural. Screenshot midpoint/overflow opsional melalui browser terisolasi.
- **Article Drafter:** riset opsional, ledger sumber/kutipan/tanggal, freshness dan kaitan paragraf–sumber; revisi per bagian dengan proposal tersimpan, persetujuan, digest dan backup; flow/mind map lokal SVG+PNG tertanam DOCX. Fetch publik default mati tanpa host allowlist. Revisi/diagram/gambar/rebuild kini memakai staging+journal untuk rollback dan pemulihan commit terputus.
- **Analytics:** satuan retensi eksplisit, pemetaan CSV generik lintas platform, kolom tak terpakai dilaporkan, retensi per adegan, observasi lokal 24h/7d dan persetujuan eksperimen. Pengguna menunda CSV asli; schema native Reels/TikTok belum diverifikasi.

## Target Windows

- Target akhir laptop Windows 10/11 x64. Ditambahkan installer inti `setup-core.bat`, prioritas venv pada launcher, dan pencarian Edge/Chrome pada Program Files/LocalAppData.
- Distribusi memakai wrapper PowerShell tipis dan pembuat ZIP Python yang diuji. Source build Short Video Factory dan modul projects di bawah src tetap masuk; data, dependency, references, credential lokal dan symlink/junction tidak ikut. Pada checkout Git, file lokal tak tercatat Git tidak ikut paket.
- ZIP source nyata berhasil dibuat dan daftar isinya diperiksa; pengujian path Windows dan file terkunci memakai fixture. Belum menjalankan CMD/PowerShell, installer, driver GPU atau TTS secara native di laptop Windows.

Alur instalasi utama kini GitHub clone/pull (`git pull --ff-only` untuk update), bukan ZIP. CI Windows native installer/launcher ditambahkan; hasilnya harus dibaca dari run GitHub Actions sebelum dinyatakan lulus. Checkpoint menolak link/junction secara eksplisit saat O_NOFOLLOW tidak tersedia.

Perbaikan CI Windows: launcher sempat ditandai gagal walaupun `/api/tools` merespons HTTP 200, karena probe sembilan aplikasi berurutan melampaui timeout klien dua detik. Ditambahkan liveness `/api/health` tanpa dependency; probe katalog diparalelkan; CI memakai liveness cepat lalu validasi katalog terpisah. Run ulang native Windows kini lulus; lihat bukti di bawah.

## Pengembangan brand/timing dan benchmark publik

- Brand kit Video Studio: katalog lokal berversi, snapshot tetap pada plan, warna/font sistem/wordmark teks untuk HTML/Lottie. Input CSS/font/URL bebas ditolak; store dibatasi, atomik dan menolak symlink/junction. Tidak ada dependency produk baru.
- Timestamp per kata menerima data eksplisit; angka/desimal/negasi, urutan dan batas adegan divalidasi. Pemicu visual berbeda per adapter dan perubahan storyboard membatalkan approval. Tidak mengklaim forced alignment terhadap suara TTS.
- Studi referensi kini mempunyai kutipan dan pengukuran cut/kata/cakupan timestamp per tiga bagian waktu. Tidak menyimpulkan makna hook/payoff otomatis.
- Benchmark memakai dua fixture publik dengan SHA256. Deteksi cut 4/5 pada sampel film; satu cut terlewat dicatat tanpa tuning default. Whisper fixture hanya menguji analyzer audio, bukan model transkripsi.
- Studi kode tambahan: Whisper (MIT), PySceneDetect (BSD-3-Clause), pin dan file bacaan ada pada REFERENCES.md; tidak menyalin kode/aset ke produk.
- Sesuai pengguna: tidak menambahkan upload audio pribadi atau manajemen antrean render; CSV asli tetap ditunda.

Validasi pengembangan ini: Chromium menguji simpan/pilih kit → mode provided → input cue kata → dua approval → Lottie final tanpa error JavaScript. Player standar lottie-web 5.12.2 juga merender judul/wordmark/font/warna/layer; ditemukan dan diperbaiki field wajib `t.m` yang sebelumnya hilang. Tidak menyamakan flag `isLoaded` dengan keberhasilan render: pengecekan mencakup isi SVG aktual dan exception renderer. Native Windows untuk commit baru dilaporkan setelah Actions selesai.
