# Audit lanjutan — 3 November 2026

## Temuan dan koreksi

- Article: ekspansi bagian menerima daftar pustaka tetapi kehilangan catatan sumber dan konteks yang dipakai penulisan awal. Kini keduanya ikut dalam permintaan ekspansi, dengan instruksi untuk menandai kekurangan bukti. Regresi memeriksa prompt aktual tahap kedua. Ini mengurangi kehilangan konteks; bukan jaminan kebenaran keluaran model.
- Clipper: NaN durasi/FPS/loudness dapat melewati perbandingan numerik. Durasi/FPS nonfinite atau nonpositif sekarang gagal; loudness nonfinite menjadi unmeasured dan needs_attention.
- Video Studio: laporan delivery kini menolak durasi nonfinite/nonpositif serta audio berlabel measured yang nilainya tidak valid.
- Runtime Remotion dipasang lokal dari lockfile untuk menjalankan typecheck dan integrasi render, tanpa mengubah versi dependency.

## Audit referensi

README terkini delapan repo katalog dibaca ulang melalui GitHub pada sesi ini. Pembacaan README tidak dianggap audit seluruh kode upstream. Peta pemanggilan kode dan pin implementasi terdahulu tetap ada pada UNIFIED-PRODUCTION-2026-11-02.md dan REFERENCES.md.

FFmpeg sudah digunakan untuk rendering, normalisasi loudness dan evaluasi delivery di kedua pipeline. Skill upstream bukan plugin runtime yang otomatis mengaktifkan seluruh kapabilitas. Pemeriksaan black/freeze/dropout yang menyeluruh belum terintegrasi. Ghost Editor/Claude Shorts memberi pola self-review, pemilihan take dan framing; Handy berkaitan dengan STT lokal; Animate dengan storyboard/render deterministik; OpenMontage dengan review produksi; Agent Reach dengan akses sumber; YouTube Automation Agent dengan orkestrasi/resume/analitik. Tidak ada penyalinan kode/aset upstream pada perubahan ini.

## Mengapa masih terpisah

Dashboard memakai stdlib Python, Clipper FastAPI/Whisper, dan renderer Node/browser. Proses dan dependency terisolasi diperlukan untuk menjaga kompatibilitas. Ketiga aplikasi memang memiliki fungsi berbeda sesuai klarifikasi pengguna: Video Studio membuat konten dari awal, Article menulis, Clipper mengolah video sumber. Handoff antar aplikasi bukan sasaran pengembangan. Prioritasnya kualitas hasil masing-masing.

## Koreksi fokus setelah klarifikasi pengguna

Ketiga aplikasi tetap mandiri sesuai fungsi. Remotion process kini menampilkan kartu instruksi dengan judul adegan yang disetujui, nomor adegan dan indikator progres; tiga node generik dihapus. Ini bukan simulasi antarmuka atau ekstraksi langkah baru oleh AI. Teks panjang dibagi menjadi baris dalam kartu.

Clipper preflight sekarang memeriksa pemotongan pada titik batas aktual dengan epsilon 1 ms; toleransi lama 30 ms dapat melewatkan potongan dekat ujung kata. Peringatan tidak menggeser waktu atau menghapus caption pengguna. Guard revisi artikel kini mempertahankan tanda plus/minus pada angka termasuk nilai mata uang; sebelumnya perubahan -3,5 menjadi 3,5 tidak terdeteksi.

## Peningkatan lanjutan

Parser sitasi bersama `citations.py` membaca kelompok/rentang numerik termasuk en dash dan titik koma. Audit tidak lagi menganggap nomor dalam rentang sitasi sebagai angka fakta; rentang terbalik/ekspansi berlebihan ditolak. Clipper menyarankan batas kata utuh melalui preflight dan menampilkannya di Studio untuk ditinjau manual, tanpa mengubah kandidat otomatis; timestamp tidak berurutan/overlap kini diberi peringatan. Kartu instruksi Remotion membatasi panjang baris berdasarkan karakter Unicode, membatasi lebar teks SVG, dan menambah pemeriksaan overflow instruksi pada frame stabil.

Validasi peningkatan lanjutan: 138 tes dashboard lulus tanpa skip termasuk render Remotion nyata; 26 tes preflight Clipper dan 8 tes UI/API terkait lulus; typecheck, 5 tes Node, Ruff F/E9, sintaks studio.js dan smoke HTTP lulus. Regresi sitasi tunggal 5.000 digit tetap dipertahankan sebagai nomor tidak dikenal tanpa konversi integer. Pemeriksaan layout belum menggantikan penilaian manusia atas keterbacaan semua ukuran/font atau kualitas editorial konten nyata.
