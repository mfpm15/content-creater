## Lanjutan sesuai arahan pengguna: fitur/menu dan optimisasi

- Autoplay/loop MP4 pada menu hasil dimatikan; preload metadata mengurangi pemuatan awal.
- Renderer memakai satu PNG cache hanya untuk state visual berurutan yang persis sama, tanpa mengurangi frame rate/durasi. Key tidak ada/tidak valid → capture normal. DOM visual tidak ditulis ulang pada state sama.
